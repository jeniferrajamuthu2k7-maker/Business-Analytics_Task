# 📊 Week 12 – Business Analysis using Tableau

## 📌 Project Overview

This project focuses on analyzing a business dataset using **Tableau Public**. The objective is to create meaningful and interactive visualizations that help identify important patterns, trends, and business insights from the data.

The dashboard combines multiple visualizations and interactive filters to make the analysis easier to understand and explore.

---

## 🎯 Objective

* Analyze the given business dataset using Tableau Public.
* Create meaningful and interactive visualizations.
* Identify important trends and patterns.
* Compare different categories and measures.
* Present key business findings through an interactive dashboard.

---

## 🛠️ Tools Used

* **Tableau Public**
* **Microsoft Excel / CSV**
* **GitHub**

---

## 📈 Visualizations

The dashboard contains multiple visualizations to analyze the dataset from different perspectives.

### 1. Visualization 1

* Used to compare important categories in the dataset.
* Helps identify higher and lower performing categories.

### 2. Visualization 2

* Shows the relationship or trend between important business measures.
* Helps understand changes and patterns in the data.

### 3. Visualization 3

* Provides another perspective of the dataset.
* Helps identify significant differences between categories.

### 4. Visualization 4

* Provides an overall summary of the selected business measures.
* Helps support comparison and decision-making.

---

## 🎛️ Interactive Filters

Interactive filters are included in the dashboard to allow users to explore the data dynamically.

Users can select different categories or values and observe how the visualizations change based on their selection.

---

## 📊 Dashboard

The final Tableau dashboard combines all the visualizations into a single interactive view.

## 🔍 Key Findings

1. The dashboard highlights differences in performance across different categories.
2. Some categories show significantly higher values compared with others.
3. The visualizations help identify important trends and patterns in the dataset.
4. Interactive filters make it easier to compare specific categories.
5. The dashboard provides a clear overview that can support business decision-making.

---

## 💡 Recommendations

1. Focus more attention on the highest-performing categories and understand the factors contributing to their performance.
2. Analyze low-performing categories further and identify possible areas for improvement.

## ✅ Conclusion

This Week 12 Tableau project helped in understanding how business data can be transformed into meaningful visual insights. The interactive dashboard makes it easier to explore the dataset, compare categories, identify trends, and derive useful business conclusions.
